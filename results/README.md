# Experiment Results

Store concise, reproducible experiment summaries here after experiments have actually been run.

Useful fields include:

- model and implementation
- dataset/version and split
- random seed and key hyperparameters
- validation and test metrics
- parameter count
- training duration
- peak GPU memory, when available
- limitations and notes

Do not add fabricated or placeholder measurements. Avoid committing large checkpoints or raw training logs.
